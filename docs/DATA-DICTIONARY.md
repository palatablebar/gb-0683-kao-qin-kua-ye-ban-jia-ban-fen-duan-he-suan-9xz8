# 夜班工时与工资

班次属于shift_day；计划结束时间不大于开始时间时跨到次日。打卡是带偏移的时间，先存UTC，再用Asia/Shanghai拆分实际日历日。休息区间按夜班日期归属处理，先从实际工作区间扣除。单班最多18小时，打卡须为整分钟。缺IN或OUT整班隔离，不猜补卡。

按实际日历日判断法定假日、周末，法定假日优先3倍、周末2倍、工作日8小时内1倍、超过8小时1.5倍；正常分钟按同员工同日累计，跨班片段共享阈值。参数holidays可传日期列表，默认仅2026-10-01。金额按片段Decimal计算到分，paid为实发工资，差额为应发减实发。此规则用于样例计算，不替代当地劳动法规。

## 跨夜支援交接（按实际责任时段核算）

裁决口径：跨夜支援**不按整班归起始班组**，而按交接时刻划分实际责任时段。交接源是独立第二数据源（参数 `handover`，UTF-8/GB18030 文本或样例名；显式传空表示本批无交接），列为 `h_id,employee,shift_day,version,at,to_team,note`，采信约定与打卡源一致（编码回退、BOM、哨兵、WIDTH隔离、(h_id,version) 去重与CONFLICT整组隔离）。

交接时刻必须带时区、落在所指班次实际 IN/OUT 窗口内（早于进场、晚于离场或找不到班次分别按 RANGE/REFERENCE 隔离）；同班交接时刻升序且不得重复。交接时刻成为切段边界：半开区间下，交接时刻（含）之后的工作时段由接收班组 `to_team` 承担，之前归起始班组 `HOME`。交接落在休息区间内时，休息仍先扣除，复工后才由接收班组承担。切段与计薪证据都带 `team` 与 `via_handover_line`（交接来源行，起始班组段为空），与原始打卡行 `line` 双向可查。

班组成本独立汇总（`team_totals`），班组分钟之和=有效分钟、班组金额之和=应发总额（`team_cost_balanced`）。交接源行数独立守恒：输入=采纳+隔离+空行+重复表头+完全重复。运行身份 `run_id` 与清单由打卡字节、参数、规则版本和**交接源sha256**共同计算：交接源晚到或修改即产生新批次与新金额，旧批次封存不动；同输入重跑身份不变，存储 INSERT OR IGNORE，不重复累计。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

同一员工/归属日/方向的最高版本若有时刻、时薪、班次、休息或实发金额冲突，则整班隔离；选中IN与OUT的时薪、班次起止与休息起止也必须完全一致。
