# 夜班反例

18位员工各有10月1日22点进、10月2日06点出。02点至03点休息，实际7小时，前两小时是假日3倍，次日5小时正常1倍，20元时薪合计220元。直接把整个夜班按归属日计假日会错算420元。脏批额外含缺时薪、冲突打卡、BOM、短行、空行与重复表头。

# 跨夜支援反例

E001 在 00:30 交接支援 LINE-B：22:00–00:30 的 150 分钟归起始班组 HOME，00:30 之后（扣除 02:00–03:00 休息）270 分钟归 LINE-B。若按整班记到起始班组，LINE-B 会少承担 270 分钟工时与对应 90 元成本。E002 在 02:30（休息区间内）交接，休息 60 分钟不计任何班组，03:00 复工后的 180 分钟才归 LINE-B。交接晚到或修改会改变交接源 sha256 与 run_id：旧批次金额原样封存，页面挂新批次，同源重跑命中同一 run_id，不会重复累计。交接脏批另含窗口外交接（RANGE）、找不到班次（REFERENCE）、同键冲突（CONFLICT）、坏时刻、缺员工与重复表头。
